# Ticket: 自动修复能力调研

**类型**: `wayfinder:research` (AFK)
**状态**: Open / Unclaimed
**阻塞**: 无

## Question

在 Windows 平台上，哪些系统设置可以通过 CLI 自动修复？修复的权限要求和风险等级是什么？

需要调研的修复能力：

| 修复项 | 方法 | 权限要求 | 风险 |
|---|---|---|---|
| 系统时区 | `tzutil /s` 或 PowerShell | 管理员 | 低 |
| 系统语言 | 注册表 / Settings API | 管理员 | 中 |
| 环境变量 | `setx` / 注册表 | 用户/管理员 | 低 |
| Node.js locale | 启动参数 / ICU 数据 | 用户 | 低 |
| 代理设置 | 系统代理 / 环境变量 | 用户/管理员 | 中 |
| Hosts 文件 | 直接编辑 | 管理员 | 高 |

**关键问题**：
1. 哪些修复需要管理员权限？能否以普通用户运行？
2. 修复后是否需要重启终端/系统才能生效？
3. 是否需要回滚能力（修复前备份当前设置）？
4. macOS/Linux 上的等价修复方法是什么（为后续扩展预留）？

**输出**：修复能力矩阵 + 权限要求 + 实现方法概要
