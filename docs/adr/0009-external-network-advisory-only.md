# VPN、路由与 DNS 配置只检测提醒，不自动修改

CC-Fix 对 VPN 客户端与隧道、网络适配器、系统或上游 DNS、路由表以及路由器配置采取只读策略。产品可以读取可公开获得的本机信号、执行非破坏性检测、解释风险并给出人工排查建议，但不能写入、切换、重启这些配置，也不能调用路由器、VPN 或 DNS 服务的第三方管理接口。

## Context

VPN、路由与 DNS 的真实拓扑由用户设备、路由器固件、运营商、企业策略、代理软件和第三方服务共同决定。相同修改在不同环境中可能导致断网、DNS 污染、策略冲突或企业网络违规，CC-Fix 无法建立足够可靠且可完整还原的所有权边界。

当前 DNS 与代理插件只读取解析结果和代理环境变量，终端也提示不会修改路由器或 VPN 配置。该边界需要成为后续 GUI、推荐系统和安装包的稳定产品契约，避免新增“一键修复 DNS/VPN”能力。

## Decision

1. VPN、路由器、路由表、网络适配器和 DNS 配置均不进入 persist 事务或自动修复清单。
2. 检测结果可以展示观察值、风险原因、置信度和通用排查步骤，但必须明确标记为“仅提醒，需要用户按自身网络环境处理”。
3. 不自动修改系统 DNS、网卡 DNS、DoH、hosts、路由表、VPN 配置、VPN 进程、路由器设置或第三方 DNS/VPN 账户。
4. 不因检测结果自动启动、停止或重启 VPN、代理、网络服务、网卡或路由器。
5. 不保存 VPN 凭据、路由器凭据、DNS 服务令牌，也不请求此类权限。
6. CC-Fix 自身拥有且已明确披露的本机设置仍可按相应 ADR 管理；如果某项操作可能影响外部网络配置，必须排除该操作并降级为提醒。

## Alternatives considered

- **按已知 VPN/路由器品牌提供自动适配**：覆盖面不可控，固件和网络拓扑差异会造成高恢复风险，因此拒绝。
- **只修改系统 DNS，其他网络项提醒**：系统 DNS 仍可能被 VPN、企业策略、网卡或路由器接管，所有权与恢复语义不足，因此拒绝。
- **提供高级用户脚本**：仍会让产品承担自动修改和恢复责任，且容易被误用，因此不作为官方功能提供。

## Testable invariants

1. 任意 persist on/off、标准保护、深度保护和地区切换都不写入外部网络配置。
2. DNS/VPN/路由相关检测不需要管理员权限，也不请求网络设备或第三方服务凭据。
3. GUI 和 CLI 对相关结果只提供提醒与人工步骤，不出现自动修复按钮或隐式执行入口。
4. 安装、升级、修复和卸载不修改 VPN、路由器、路由表、网卡或 DNS 配置。
5. 自动化测试使用 mock 或隔离网络环境，不改变执行机器的真实网络配置。

## Consequences

产品不会因错误识别用户网络拓扑而造成断网或破坏企业/家庭网络配置，安装包也无需获得网络设备管理权限。代价是 CC-Fix 不能承诺自动消除所有 DNS、VPN 或路由风险；用户必须根据自己的网络环境完成外部配置调整。
