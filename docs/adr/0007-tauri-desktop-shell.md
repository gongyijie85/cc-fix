# 使用 Tauri 薄壳托管按会话启动的本地 GUI 服务

CC-Fix 的现有 HTML、HTTP/SSE 接口、检测核心和修复核心继续由同一 Node bundle 提供；Windows 桌面入口采用 Tauri v2/WebView2 薄壳，只负责窗口、单实例、本地服务生命周期、启动错误、恢复入口和权限协调。CLI 是独立入口，与桌面壳共享私有 Node.js 24 LTS 运行时和核心 bundle，不通过桌面进程转发命令。

这一形态已由 throwaway 原型验证：Tauri 2.11.5 可以启动随便携目录提供的 Node.js 24.18.1 和现有 GUI bundle；主窗口能够加载现有页面；第二次启动聚焦已有窗口；指定端口冲突时自动选择新的回环端口；正常关窗会同时回收桌面进程与 Node 子进程。原型分支仅作为决策的一手证据，不合并入主线。

## Lifecycle

桌面壳每次启动创建一个桌面会话：获取当前用户范围的单实例所有权，选择可用随机回环端口，生成高熵一次性令牌，启动私有 Node 本地 GUI 服务，等待带身份的就绪握手，然后创建 WebView 主窗口。再次启动只聚焦已有窗口，不创建第二个服务。

关闭主窗口默认彻底退出且不驻留托盘。没有修改事务时，桌面壳先请求服务优雅停止，超时后再终止子进程；修改事务进行中则拦截首次关闭并显示“正在安全完成当前操作”。用户再次确认强制退出前，服务必须保证事务日志已经耐久落盘，使下次启动能按 ADR-0006 恢复。

异常退出后若存在未完成事务，下一次启动进入专用“需要恢复”页，展示请求目标、已完成步骤与安全恢复动作。恢复完成前禁止新的修改操作，但允许状态查看、只读检测和诊断导出。

## Localhost security

本地 GUI 服务只绑定 `127.0.0.1`，端口冲突时自动重新选择。随机端口不是安全边界：首次加载使用含一次性高熵令牌的引导地址建立 `HttpOnly`、`SameSite=Strict` 会话，随后删除可见 URL 中的令牌；所有 API、SSE 和修改请求都验证会话，并校验 `Host`、`Origin` 和回环来源。令牌仅存于当前桌面会话内存，应用退出后失效。

生产实现还应让壳验证服务就绪消息中的会话 ID，避免端口选择与服务绑定之间的竞争被其他本地进程冒用。WebView 不开放任意远程导航或通用 shell/文件系统能力。

## Failure and privilege boundaries

私有运行时、WebView2、本地服务或认证握手启动失败时，桌面壳显示轻量原生错误页，提供失败类别、日志位置、重试和复制诊断信息；不自动退回系统浏览器。诊断日志存放于 `%LOCALAPPDATA%\CC-Fix\logs`，滚动保留并默认脱敏；可恢复备份和操作历史继续存放于 `%APPDATA%\cc-fix`。

桌面应用和本地 GUI 服务默认保持普通用户权限。需要写入受保护浏览器策略时，经用户确认启动短生命周期特权助手；助手只接受结构化、白名单化且绑定当前事务的策略写入请求，不接受任意命令、脚本或路径。助手完成即退出，普通权限服务读回验证并继续事务。

安装器不得假设 WebView2 已存在。它检测 Evergreen WebView2 Runtime，缺失时使用安装包内携带的 Microsoft x64 离线安装器补齐；失败则明确终止安装，避免首次启动依赖联网。

## Consequences

桌面入口可以复用现有 GUI 与核心，避免 Electron 重写和 CLI/GUI 双实现。代价是需要维护受认证的 localhost 会话、私有 Node 子进程、WebView2 前置和严格收口的特权助手。正式实现必须补充启动失败、端口竞争、单实例、强制退出、服务崩溃、认证拒绝、提权取消与恢复页的 Windows 集成测试。
