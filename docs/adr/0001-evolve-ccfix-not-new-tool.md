# 在 cc-fix 上演进"一键切换"体验，不新建工具

用户提出"做一个小工具：检测、修复、自动备份、一键切换、一键还原日常配置"。经逐项核对，需求的 80% 已由 cc-fix 现有能力覆盖（check 检测、persist on/off 修复与备份恢复、GUI 按钮）。决定在 cc-fix 上演进补齐剩余缺口（操作日志、地区选择器、桌面快捷方式、按钮文案），而非新建工具。

## Considered Options

- **新建独立工具**：被否。检测引擎、备份机制、事件流、GUI 全部要重写，纯重复劳动且产生两个事实源。
- **演进 cc-fix**：采纳。缺口是增量式的，每项都能挂在现有编排层/事件协议上。

## Consequences

后续同类"我想要一个 XX 小工具"的需求，第一步应先对照现有能力盘点，确认是缺口还是重复。
