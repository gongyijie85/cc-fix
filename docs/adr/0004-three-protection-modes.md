# 三态保护模式与独立健康状态

cc-fix 的持久化采用日常、标准保护、深度保护三种模式：标准保护对齐核心信号并保留 Windows 日常语言与区域偏好，深度保护在此基础上进一步对齐系统语言和区域画像。模式只代表最后一次完整成功提交的状态，实际漂移或部分失败由独立的保护健康状态表达；所有保护转换共享首次离开日常状态时创建的不可覆盖原始备份，避免升级、降级和重复开启污染还原基线。

## Consequences

不带保护强度的重复开启只重新对齐当前模式，不隐式降级；标准与深度之间允许直接转换，转换全部成功后才提交新模式。GUI 对深度保护明确提示影响，CLI 通过显式参数确认，操作日志同时记录请求转换与最终提交状态。
