# 单一备份快照 + 追加式操作日志，不做多份历史备份

用户希望"修复前自动备份一下记录"并可回看。备份的语义是"最原始值"（createBackup 发现已有备份即复用不覆盖），若保留多份历史备份，会引入"恢复到哪一份"的决策负担，且与"不覆盖最原始值"的既有不变量冲突。决定维持单一快照（`persist-backup.json`，off 成功后删除），"有记录"诉求由追加式操作日志（`%APPDATA%\cc-fix\history.jsonl`，每次 on/off/check 完成追加一行，GUI 显示最近 10 条）承担。

## Considered Options

- **多份历史备份 + 选择恢复点**：被否。备份语义从"安全网"变成"版本库"，恢复路径从一键变成选择题，且旧快照的"原始值"可能已被后续操作污染。
- **单一快照 + 操作日志**：采纳。各回答各的问题——快照负责可恢复，日志负责可追溯。
